# Tokiva-App-BE

Backend API (Fastify + Supabase + Hugging Face / Kaggle AI Pipeline + Resend) untuk sistem kasir Tokiva POS.

## Setup Lokal

1. Salin `.env.example` menjadi `.env` dan isi kredensial masing-masing.
2. Instal dependensi: `npm install`
3. Jalankan tes: `npm test`
4. Jalankan server: `npm run dev`
